# Run on Windows (quick)

## 1) Open terminal in this folder
- Open the folder in Explorer
- Click the address bar, type `cmd`, press Enter

## 2) Install
```bat
npm install
```
This will also install dependencies inside `apps/server` and `apps/client` automatically.

## 3) Run dev (server + client)
```bat
npm run dev
```

## 4) Open
- http://localhost:5173

## If you use PowerShell and see "running scripts is disabled"
Use CMD instead, or run npm via:
```powershell
npm.cmd install
npm.cmd run dev
```
